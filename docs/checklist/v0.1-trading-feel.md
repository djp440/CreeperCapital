# 苦力怕资本 v0.1 交易手感验收清单（4 级：人工操作）

对应 spec #1 的 ticket #20。自动化测试（core 单元测试、GameTest、`restart-e2e.ps1`、自动截图）已经证明“规则算得对”，这份清单只验证机器判断不了的：**用起来顺不顺、反馈及时不及时、数字刺不刺眼、看得清看不清**。

每一项都带清单标记，勾选 `[x]` 表示手感可接受；觉得别扭就在“用户反馈”里写一句（越具体越好，例如“成交后余额要等约 1 秒才变”），不用写解决方案。

## 准备

### 环境

- **单人验收（除下面三项外的所有项）**：`./gradlew :neoforge:runClient`，新建单人世界，**开启作弊**（开发命令要 OP）。单人世界里退出到标题界面服务器就停了，市场也停，所以“离线”和“重启”相关项必须用专用服务端。
- **需要专用服务端的项（D5、M2、O1，L1 改配置也建议用它）**：`./gradlew :neoforge:runServer` 起专用服务端（控制台可直接输入命令，不带斜杠；开发环境跳过 EULA），再用 `./gradlew :neoforge:runClient` 的客户端连 `localhost`。第二名玩家（D5）需要另一个客户端（另一台电脑，或启动器装 NeoForge 26.1.2 + 本仓库构建出的 jar，服务端 `server.properties` 设 `online-mode=false` 后可用任意用户名）。
- 第一次进世界后市场已有 30 个市场日历史；市场时间 1 真实秒 = 6 市场秒，1 个市场日约 4 真实小时，**资金费每 8 市场小时（约 80 真实分钟）才结算一次**，所以要看结算请用 `market funding` 命令快进，别干等。

### 开发命令速查（均要 OP；`<玩家>` 可写 `@s` 或名字）

| 命令 | 作用 |
|---|---|
| `/creeper` | 打开交易界面（所有玩家可用，默认快捷键 K，可在按键设置里改绑，分类“苦力怕资本”） |
| `/creeper dev deposit <玩家> <金额>` / `withdraw` | 给合约账户充值 / 扣除 CRP（最多 6 位小数，离线玩家也行） |
| `/creeper dev pool fund <金额>` | 给流动性池注资（池子初始 1,000,000 CRP） |
| `/creeper dev market pause` / `resume` | 暂停 / 恢复市场 |
| `/creeper dev market advance <1..150000>` | 把行情快进若干步（约 150000 步 = 10 个市场日；只广播最后一步，**中途的挂单触发、资金费、强平检查会被跳过**） |
| `/creeper dev market funding <1..30>` | 精确快进到后续第 N 个资金费结算点 |
| `/creeper dev market jump <合约> <百分比>` | 在下一个行情步让合约价格跳变，范围 -99 到 1000，如 `-20` 跌 20%（同一步内多次发会叠加；标记价格平滑跟随，必要时再等 1 到 2 步或再发一次） |

内置合约：`DIAMONDCRP`（起始 1000 CRP，最高 125x，数量 3 位小数）、`GUNPOWDERCRP`（起始 100 CRP，最高 50x，数量为整数）。默认费率：taker 0.05%，maker 0.02%，强平清算费 0.5%。缺省杠杆分档下，高杠杆只允许小仓位（例如 20x 约 5,000 CRP 名义价值封顶），要开大仓请用低杠杆（下面各项已注明）。

### 建议的验收账号状态

除非另有说明，每个小节开始前先 `/creeper dev deposit @s 100000`，并保证没有遗留仓位和委托（资产页“可用余额”约 100,000）。

## D. 盘口、最新成交与滑点

- [ ] **D1 盘口观感**
  - 内容：图表与下单面板之间的“盘口”页。
  - 操作说明：打开盘口页签，观察卖盘（红在上）、中间最新价、买盘（绿在下）和深度条。
  - 预期效果：每档显示价格 / 数量 / 累计，深度条长度随累计递增；点差内的最新价居中；随行情步价格移动整体上下平移。
  - 手感标准：数字右对齐、深度条不遮挡数字；刷新时不抖动不闪。
  - 用户反馈：

- [ ] **D2 大单与小单的滑点对比**
  - 内容：虚拟流动性曲线（市价单按沿曲线的均价成交）。
  - 操作说明：在 DIAMONDCRP，杠杆调成 5x，逐仓。先市价开多 1（约 1000 CRP 名义）并看成交提示和成交历史的成交价；平掉；再开多 50（约 50000 CRP 名义，仓位页看开仓均价）；平掉。两次的成交价相对开仓瞬间的最新价各差多少。
  - 预期效果：小单成交价几乎等于“最新价 + 半个点差”；大单成交价明显更差（开多更贵、平多更便宜），差距随数量增大；盘口里能找到对应的档位深度。参考：10,000 CRP 名义的单子，钻石平均滑点约 0.05% 加半个点差，火药约 0.3% 加半个点差。
  - 手感标准：玩家能凭盘口直觉预判“这单会吃到哪几档”；大单的滑点既真实可感，又不至于让游戏玩不下去。
  - 用户反馈：

- [ ] **D3 下单面板预估与实际成交的差距（已知限制，请给感受）**
  - 内容：面板的“预估成交价 / 预估保证金 / 预估手续费”目前按最新价计算，没有接虚拟流动性曲线（见 memo-16；如 #20 已接曲线则以实际为准）。
  - 操作说明：数量框输入一个大数量（如 50），对比面板预估成交价与实际成交价（成交提示 / 成交历史）。
  - 预期效果：大单时两者可能不一致。
  - 手感标准：请判断这个差距是否会让人觉得“被骗了”；如果会，说明需要把预估接上曲线。
  - 用户反馈：

- [ ] **D4 最新成交面板**
  - 内容：右侧栏“最新成交”页（英文页签 Trades）。
  - 操作说明：切到“最新成交”页，静看 20 秒；鼠标放在栏内滚轮向下翻旧成交。
  - 预期效果：每秒新增 2 到 8 笔模拟成交，最新在最上，买入 / 卖出颜色区分；滚轮可以翻看旧成交；没有成交时显示“暂无成交”。
  - 手感标准：节奏像真实交易所而不是刷屏；翻看旧成交时不会被新成交强制拉回顶部或抖动。
  - 用户反馈：

- [ ] **D5 多人：别的玩家的成交出现在最新成交里**
  - 内容：玩家成交广播（需两名玩家）。
  - 操作说明：玩家 A 开着“最新成交”页，玩家 B 在同一合约市价开多 / 平仓若干次。
  - 预期效果：A 的面板里出现 B 的成交，整行黄色半透明底加左侧色条，多占一行写“玩家 B”，买入 / 卖出方向正确；A 自己的成交也会高亮。
  - 手感标准：玩家成交一眼可见；已知它会被每秒 2 到 8 笔模拟成交很快挤出 13 行可视范围（约 2 到 3 秒）——请判断这个停留时间是否够用，是否需要置顶最近玩家成交（见 memo-18）。
  - 用户反馈：

## F. 保证金模式与杠杆

- [ ] **F1 逐仓 / 全仓切换**
  - 内容：下单面板头部的“逐仓 / 全仓”按钮。
  - 操作说明：无仓位无挂单时点击切换；开一个仓位后再点；挂一个限价单后（见 H）再点。
  - 预期效果：无仓位无挂单时可切，提示“xxx 已切换为全仓 / 逐仓”，仓位页合约列标注“全仓 / 逐仓 + 杠杆”；有仓位或挂单时拒绝并提示“有仓位或委托，不能切换”。
  - 手感标准：当前模式一眼可辨；按钮点击有悬停高亮。
  - 用户反馈：

- [ ] **F2 杠杆调整与限制**
  - 内容：杠杆“− / +”按钮。
  - 操作说明：无仓位时点 + 把钻石杠杆调到 125x（最高），再 −；开 5x 仓位后调整为 3x、8x；名义价值较大时（开 5x、30 个钻石，约 30000 CRP）尝试调到 100x（该名义价值所在档位最高 50x，应被拒绝）。
  - 预期效果：杠杆显示在两个按钮之间，到 1x / 最高时对应按钮变灰；有仓位时调整即时生效并提示“杠杆已调整为 …”；超过当前名义价值所在档位的最高杠杆时提示该档上限；调高杠杆（退保证金）会导致保证金率达到 100% 时被拒绝。
  - 手感标准：连点响应顺畅，数值不抖动；提示里的档位数字与仓位页一致。
  - 用户反馈：

- [ ] **F3 预估强平价与保证金率**
  - 内容：仓位页“预估强平价”“保证金率”两列及颜色。
  - 操作说明：逐仓 10x 多头一个；观察强平价（应低于开仓价约 9% 到 10%）；用 `jump DIAMONDCRP -5` 看保证金率上升。全仓下重复。
  - 预期效果：保证金率随价格下跌上升，≥ 50% 变黄、≥ 80% 变红（不同涨跌色方案下都清晰可辨）；展示的预估强平价与 I 项实际被强平的价格一致。
  - 手感标准：风险升高时颜色变化来得及提醒玩家，不是已经强平了才红。
  - 用户反馈：

## H. 限价委托

- [ ] **H1 挂限价单：冻结与提示**
  - 内容：下单面板“限价”模式。
  - 操作说明：切到“限价”，DIAMONDCRP 10x，委托价填比最新价低 3% 的价（开多不会立刻成交），数量 2，点开多。
  - 预期效果：提示“已挂单 … @ …”；资产页可用余额下降（冻结 = 保证金 + maker 手续费）；“当前委托”页出现该单，含冻结金额与“撤单”按钮；成交历史无新记录。
  - 手感标准：委托价框占位提示清晰；挂单后可立刻继续操作，不需要关界面。
  - 用户反馈：

- [ ] **H2 撤单**
  - 内容：当前委托页“撤单”按钮。
