# 指数价格 + 溢价的双层定价

行情算法只生成**指数价格**，**最新价格** = 指数价格 × (1 + **溢价**)，**标记价格**和**资金费率**按币安公式由这两者推导。首版溢价是一个随市场状态变化的随机过程；玩家成交只产生**临时冲击**，即沿虚拟流动性曲线产生滑点，成交后价格立即复原。这样既保留了币安「指数 / 标记 / 最新」三种价格，又给「玩家交易影响价格」留出了唯一的接口：将来让一部分冲击留在溢价里，变成**永久冲击**，再由资金费率自然拉回。指数价格永远不受玩家影响。

## Considered Options

- **GMX 式单一预言机价格**：三种价格合而为一，资金费率只能按多空不平衡来收，不像币安。
- **纯虚拟 AMM（Perp v1 式）**：价格完全由池子曲线决定，首版就引入了玩家影响，行情也很难调得逼真。
