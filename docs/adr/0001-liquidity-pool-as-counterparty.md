# 流动性池作为全体玩家的对手方

苦力怕资本不撮合玩家之间的委托，所有成交都以**流动性池**为对手方。原因是服务器玩家少，订单簿形成不了有效深度，这也是项目一开始就定下的简化。池子持有**有限**的苦力怕币，不能凭空发币。这样苦力怕币将来接入经济系统时不会通胀，也能完整还原币安的风险链条：穿仓亏损先由独立的**风险保障基金**承担，基金不够再由池子承担，池子付不出盈利时触发 **ADL**。手续费归池子，强平剩余的保证金和清算费归基金。

## Considered Options

- **订单簿撮合**：玩家太少，盘口长期为空。
- **无限庄家**（盈利增发、亏损销毁）：最简单，但会通胀，也没有基金和 ADL 可言。
- **把基金并入池子**：系统账户少一个，但失去币安「基金先兜底、再触发 ADL」的语义。
